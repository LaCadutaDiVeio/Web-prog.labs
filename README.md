

# Pet-проект в рамках курса "Технологии Web-программирования"
Аналог Jira с визуализацией зависимостей задач в виде графа.

Стек: FastAPI, SQLAlchemy, PostgreSQL, React, Docker.

## Прогресс по лабораторным
| № | Тема | Ветка | Тег | Статус |
|---|------|-------|-----|--------|
| 1 | HTML/CSS вёрстка           | `lab-01` | `lab-01-passed` | ⏳ |
| 2 | React-компоненты           | `lab-02` | `lab-02-passed` | ⏳ |
| 3 | FastAPI + Docker           | `lab-03` | `lab-03-passed` | ⏳ |
| 4 | БД + SQLAlchemy + Alembic  | `lab-04` | `lab-04-passed` | ⏳ |
| 5 | REST API                   | `lab-05` | `lab-05-passed` | ⏳ |
| 6 | Frontend ↔ API             | `lab-06` | `lab-06-passed` | ⏳ |

## Структура

- `backend/` — FastAPI-приложение
- `frontend/` — React
- `docs/` — отчёты по лабораторным
